# Packet Tracer NDAIC Labs

This repository contains Cisco Packet Tracer lab activities for the NDAIC (Networking and Data Communications course). Each lab focuses on specific networking concepts and skills.

## Lab Overview

The following labs are included in this repository:

### 1. Implement Basic Connectivity (`Implement Basic Connectivity.pka`)
- **Commit**: `dd60592` - "Lab: Add initial implementation of Basic Connectivity"
- **Focus**: Fundamental network connectivity concepts, including device setup and basic IP configuration
- **Skills**: Setting up end devices, routers, and establishing basic IP connectivity

### 2. Test and Correct Network Connectivity using ICMP (`_Use ICMP to Test and Correct Network Connectivity.pka`)
- **Commit**: `91a9abe` - "Lab: Test and Correct Network Connectivity using ICMP"
- **Focus**: Using Internet Control Message Protocol (ICMP) to test and troubleshoot network connectivity
- **Skills**: Using `ping` and `traceroute`/`tracert` commands, interpreting ICMP responses, diagnosing connectivity issues

### 3. Configure Initial Router Settings (`Configure Initial Router Settings.pka`)
- **Focus**: Initial router configuration and setup
- **Skills**: Initializing routers, basic CLI configuration, setting hostname, passwords, and interface descriptions

### 4. Configure SSH (`Configure SSH.pka`)
- **Focus**: Secure Shell (SSH) configuration for remote management
- **Skills**: Setting up SSH on routers, configuring usernames and passwords, enabling secure remote access

### 5. Troubleshoot Default Gateway Issues (`Troubleshoot Default Gateway Issues.pka`)
- **Focus**: Identifying and resolving default gateway configuration problems
- **Skills**: Diagnosing connectivity issues when default gateway is misconfigured, verifying IP addressing, troubleshooting layer 3 connectivity

### 6. Use Ping and Traceroute to Test Network Connectivity (`Use Ping and Traceroute to Test Network Connectivity.pka`)
- **Focus**: Network diagnostics using ping and traceroute/tracert
- **Skills**: Testing connectivity between devices, identifying path taken by packets, troubleshooting network issues

### 7. Verify IPv4 and IPv6 Addressing (`Verify IPv4 and IPv6 Addressing.pka`)
- **Focus**: IPv4 and IPv6 addressing verification and validation
- **Skills**: Configuring and verifying IPv4 addresses, understanding IPv6 addressing schemes, validating network configuration

### 8. Build a Switch and Router Network (`11.4.4-packet-tracer-tutored-activity---build-a-switch-and-router-network.pksz`)
- **Focus**: Comprehensive network design with switches and routers
- **Skills**: Creating network topologies, configuring VLANs, inter-VLAN routing, switch management, and router configuration for end-to-end connectivity

## Course Structure

These labs follow a progressive learning path from basic connectivity concepts to more advanced network troubleshooting and configuration:

1. **Foundation**: Basic connectivity and IP addressing
2. **Diagnostics**: Ping, traceroute, and ICMP troubleshooting
3. **Configuration**: Router setup, SSH, and initial configuration
4. **Advanced**: VLANs, inter-VLAN routing, and complex network topologies

## How to Use These Labs

1. Open each `.pka` file using Cisco Packet Tracer software
2. Follow the lab instructions to complete the activities
3. Use the diagnostic commands (`ping`, `traceroute`, etc.) as specified
4. Document your findings and configuration changes

## Dependencies

- Cisco Packet Tracer (version 21.4.4 or compatible)
- Basic understanding of networking concepts (IP addressing, DNS, DHCP, etc.)
